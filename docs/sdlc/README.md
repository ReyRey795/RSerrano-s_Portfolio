# Software Development Life Cycle Documentation

## Purpose

This directory documents how I applied the Software Development Life Cycle (SDLC) while planning, designing, implementing, testing, and maintaining my personal portfolio website.

These artifacts preserve the reasoning behind the website's structure and interactions. They also provide a record of how the design evolved throughout development.

## Project Scope

The portfolio uses a five-page architecture:

1. Home / Dossier
2. The Journey
3. Résumé
4. Cover Letter
5. Career Goals

The Journey page contains four internal chapters:

1. Army
2. Construction
3. Discovery
4. Engineering and Projects

## Intended Users

The portfolio is designed primarily for:

- Technical hiring managers and recruiters
- Software engineering professionals
- Academic evaluators
- Professional networking contacts

## Design Evolution

The version numbers show how the design changed during planning.

- **V1 wireframes** establish the initial page layouts and interaction concepts.
- **V2 diagrams** reflect the decision to consolidate four separate Journey pages into one interactive page with four internal chapters.

This revision reduced navigation complexity while preserving the chapter-based career story.
