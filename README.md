# Reynaldo Serrano Portfolio

A personal portfolio designed to tell the story of my non-traditional career path from military aviation, through the construction industry, into software engineering.

This project is also being used to satisfy the requirements of WGU's D276 course while building something intended to continue growing beyond the course.

## Project Objective

The immediate objective is to meet all applicable WGU course requirements.

The larger objective is to create an interactive professional portfolio that gives employers a better understanding of who I am, what I have done, how I reached this point in my career, and what I am actively building toward.

Rather than presenting my experience only as a traditional résumé, the portfolio is designed around a career journey:

**Army → Construction → Discovery → Engineering**

Each stage is intended to show not only what I did, but what I learned and how those skills contributed to the next stage.

## Development Approach

This redesign is being built using the Software Development Life Cycle (SDLC).

The project is being developed in small, testable increments with Git commits documenting meaningful changes throughout development.

The SDLC documentation will be maintained separately from the public-facing website inside the repository.

Planned documentation includes:

* Project planning
* Requirements analysis
* Sitemap iterations
* User-flow diagrams
* Wireframes
* Design decisions
* Development notes
* Testing plans and results
* Deployment documentation
* Future improvements

## Planned Website Architecture

The final Version 1 portfolio is planned as a five-page website:

* `index.html` — Home / Dossier
* `journey.html` — Career Journey
* `resume.html` — Résumé
* `cover-letter.html` — Cover Letter
* `career-goals.html` — Career Goals

The Journey page will contain four internal chapters:

1. Army
2. Construction
3. Discovery / FiveM
4. Engineering + Projects

## Design Direction

The portfolio begins with a classified personnel dossier in a dark intelligence-review environment.

After the dossier is declassified, the website gradually changes visually as the career story progresses:

**Military dossier → Construction blueprints → Development environment → Modern engineering workspace**

The goal is for the visual design to reinforce the career story rather than simply decorate the website.

## Responsive Design

The website is being designed for both desktop and mobile use.

Desktop and laptop versions will provide the richest interactive experience, including persistent navigation and chapter transitions.

Mobile layouts will preserve the same information and navigation while simplifying interactions where necessary for usability and performance.

## Technologies

Version 1 is being built using:

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* Local image, audio, and video assets

The project intentionally avoids unnecessary frameworks so the underlying HTML, CSS, and JavaScript concepts remain visible and understandable.
